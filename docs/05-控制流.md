# 控制流

本章示例默认使用自动类型：参数在调用点单态化，返回类型由 `return` 推断。写全型（`def classify(score: int) -> str:`）同样合法，两者行为一致。

## 6.1 if / elif / else

```python
def classify(score):
    if score >= 90:
        return "A"
    elif score >= 60:
        return "B"
    else:
        return "F"
```

条件必须是 `bool`（`while` 同理）。没有 C 风格的"非零即真"：`if 1:` 报类型错误。`elif` 可多层；`else` 可选。

## 6.2 while

```python
def countDown(n):
    steps = 0
    while n > 0:
        n -= 1
        steps += 1
    return steps
```

`break` 跳出循环、`continue` 下一轮；两者不在循环内使用报 E2009。

## 6.3 for：两条硬规则

### 规则一：可遍历 range、List、str、Dict、Set

```python
for i in range(10):        # range(n)：0 .. n-1
    print(str(i))

for v in ["a", "b"]:       # 遍历 List
    print(v)

for ch in "abc":           # 遍历 str：逐个字符
    print(ch)

for key in {"a": 1}:       # 遍历 Dict：默认键
    print(key)

for v in {1, 2, 3}:        # 遍历 Set
    print(str(v))
```

- `range(n)` 中 `n <= 0` 时为空区间，循环零次（与 Python 一致）；
- `range` 不是列表：不支持 `len(range(5))` 或下标；
- **张量不可遍历**：`for row in t:` 报 E2001；
- 一维数值字面量是 `List`（第 11 章），所以 `for x in [1, 2, 3]:` 合法；嵌套字面量 `[[1,2],[3,4]]` 是 `Tensor`，不可遍历。

### 规则二：循环变量可复用同名（含嵌套）

循环变量是循环体内的新局部变量。**同一函数内顺序与嵌套复用同名循环变量均合法，语义与 Python 一致**——下面这段正常：

```python
def emptyRange():            # 合法，输出 0
    hits = 0
    for i in range(0):       # 第一次：i 进入作用域
        hits += 1
    for i in range(-5):      # 顺序复用同名 i：允许
        hits += 1
    return hits
```

> **同名复用的实现契约**：迭代器/计数器是**循环内部状态**（不进名字映射），因此顺序与嵌套复用同名循环变量均数值正确、语义与 Python 一致（`probe_n_nested_same` → 3、`probe_n_reply_example` → 4，run 与 build 双模一致）。
>
> 结论：同名循环变量（顺序或嵌套）现在都安全；若为了可读性区分作用域，仍可用不同名（`i` / `j` / `k`…）。

## 6.4 break / continue / pass

```python
def skipPattern(n):
    total = 0
    for i in range(n):
        if i % 3 == 0:
            continue        # 跳过 3 的倍数
        if i > 8:
            break           # 大于 8 停止
        total += i
    return total            # skipPattern(20) → 1+2+4+5+7+8 = 27
```

嵌套循环中 `break` 只跳出最内层：

```python
def nested(n):
    acc = 0
    for i in range(n):
        for j in range(n):
            if j > i:
                break       # 只跳出内层
            acc += 1
    return acc              # nested(4) → 1+2+3+4 = 10
```

`pass` 是空语句占位，用于"语法上需要语句但语义上不需要"的位置：

```python
def placeholder(flag):
    if flag:
        pass
    else:
        pass
    return 0
```

## 6.5 实战模式：在 List[bool] 中查找第一个 True

结合 List 与 for，可以写出干净的"查找"模式（这也是 List 当前最实用的场景）：

```python
def firstTrue(flags):
    idx = 0
    for v in flags:
        if v:
            return idx
        idx += 1
    return -1
```

> **实测记录**（`t05_control.sg` 全量输出）：
> ```
> $ scg run t05_control.sg
> A B F
> 2
> 5
> 27
> 10
> 0
> 0
> 0
> 1
> 2
> ```

对应源码（节选）：

```python
def classify(score):
    if score >= 90:
        return "A"
    elif score >= 60:
        return "B"
    else:
        return "F"

def firstTrue(flags):
    idx = 0
    for v in flags:
        if v:
            return idx
        idx += 1
    return -1

def countDown(n):
    steps = 0
    while n > 0:
        n -= 1
        steps += 1
    return steps

def skipPattern(n):
    total = 0
    for i in range(n):
        if i % 3 == 0:
            continue
        if i > 8:
            break
        total += i
    return total

def nested(n):
    acc = 0
    for i in range(n):
        for j in range(n):
            if j > i:
                break
            acc += 1
    return acc

def emptyRange():
    hits = 0
    for i in range(0):
        hits += 1
    for i in range(-5):     # 顺序复用同名 i 合法
        hits += 1
    return hits

def main():
    print(classify(95), classify(70), classify(50))   # A B F
    flags = [False, False, True, False]
    print(firstTrue(flags))                            # 2
    print(countDown(5))                                # 5
    print(skipPattern(20))                             # 27
    print(nested(4))                                   # 10
    print(emptyRange())                                # 0
    for i in range(3):
        print(i)                                       # 0 1 2
    return 0
```
