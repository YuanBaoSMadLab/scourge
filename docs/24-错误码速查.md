# 附录 B 错误码速查

> 编号即契约：一旦发布，编号含义永不变更、永不复用。来源：`include\scourge\Common\ErrorCodes.hpp`。诊断格式：`文件:行:列: error[码]: 消息`（`--json` 为结构化数组）。

## B.1 E1xxx 语法（Lexer / Parser）

| 码 | 名称 | 触发场景（本书实测） |
|---|---|---|
| E1001 | IllegalChar | 非法字符（不属语言字符集） |
| E1002 | UnterminatedString | 字符串未闭合 |
| E1003 | BadNumber | 数字字面量格式错误 |
| E1004 | BadIndentation | **Tab 缩进**（只允许空格） |
| E1005 | UnexpectedToken | 意外记号；括号外语句被裸换行折断；语句后缺少换行。**注：括号内跨行续写已支持（D1），不会触发本码** |
| E1006 | InvalidAssignTarget | 非法赋值目标；模块顶层赋值目标必须是变量名 |
| E1007 | UnsupportedFeature | 明确拒绝清单：链式比较、元组字面量、from-import、函数头等值、AOT 不支持的构造（见下"E1007 的 AOT 后端清单"） |

### E1007 的 AOT 后端清单（run 可用、build 拒绝）

以下构造在早期版本曾于 `run`（VM）模式下正常工作、在 `build`（AOT）后端被 `E1007` 显式拒绝（非崩溃、非回归，是 AOT 后端尚未实现）。**当前仍拦 4 类**，其余已解锁：

| 触发写法 | E1007 消息片段 | 当前状态 |
|---|---|---|
| 模块顶层张量全局变量 `A = [[...]]` | AOT 暂不支持：全局变量 'A' 的类型 | **仍拦** |
| `2 ** -1`（负整数字面量指数） | AOT 暂不支持：整数幂需要非负整数字面量指数 | **仍拦** |
| `print(r)`（Result 整体打印） | AOT 暂不支持：print 该参数类型 | **仍拦** |
| `"a" in words`（str 上 `in`） | AOT 暂不支持：'in' 仅支持 str 右操作数 | 解锁 |
| `print(xs)`（`xs: List[int]`/`List[str]`） | AOT 暂不支持：print 该参数类型 | 解锁（List 部分；Result 仍拦） |
| `for v in flags`（`flags: List[bool]`） | AOT 暂不支持：该元素类型的列表 for 迭代 | 已解锁 |
| `xs[i]`（`xs: List[int]`） | AOT 暂不支持：该元素类型的列表下标读取 | 解锁 |
| `async def f: ...`（模块顶层） | AOT 暂不支持：async def | **顶层仍拦**；函数内嵌套形态  可 build |

## B.2 E2xxx 类型与形状（TypeChecker）

| 码 | 名称 | 触发场景（本书实测） |
|---|---|---|
| E2001 | TypeMismatch | 赋值/运算/实参类型不符；实参数量不符；`for` 遍历张量（str/List/Dict/Set 可遍历）；张量不支持 `in`；跨模块调用未注解参数的导入函数 |
| E2002 | CannotInfer | `x = []` 且到作用域结束仍无写入定型；**变量声明缺少初值 `x: int`**；递归/前向引用且返回类型未注解 |
| E2003 | UnknownName | 未声明标识符；成员不存在（如 `r.is_ok` 裸访问、`None` 上调用 `is_none`） |
| E2004 | ShapeMismatch | 张量形状/秩不符；字面量各行长度不一；`transpose` 非二维 |
| E2005 | ResultNotConsumed | Result 值被丢弃（必须绑定/判断/取值） |
| E2006 | ReturnTypeConflict | 多个 return 分支类型不一致 |
| E2007 | DuplicateDefinition | 重复定义；模块级/def 级使用内建名 |
| E2008 | UnknownType | 未知类型名 |
| E2009 | BreakOutsideLoop | break/continue 不在循环内 |
| E2010 | AwaitOutsideAsync | await 出现在非 async 函数内 |

## B.3 E3xxx 契约

| 码 | 名称 | 触发场景 |
|---|---|---|
| E3001 | ContractViolated | 调用点静态违反 `requires` |
| E3002 | ContractTypeError | 契约表达式非 bool；空契约表达式 |
| W3001 | ContractDowngraded | 契约不可静态验证，降级为运行时断言（**警告**） |

## B.4 E5xxx 外部边界

| 码 | 名称 | 触发场景 |
|---|---|---|
| E5001 | ModuleNotFound | import 目标未找到（注意：参数解析失败时也复用此码） |
| E5002 | ImportCycle | 循环依赖 |
| E5003 | MissingExport | from-import 成员不存在（预留） |

## B.5 运行时 panic（无错误码，走 stderr + 退出码 1）

整数溢出（`+ - * **` 取负）、整除/取模除零、浮点除零、下标越界、`assert` 失败、`Result` unwrap 失败、矩阵乘维度不匹配（运行时形态）、空张量取极值、int 张量赋非整数值。全部可被 `try/except` 捕获。

## B.6 退出码

| 码 | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 诊断错误（检查失败/panic） |
| 2 | 用法错误 |
