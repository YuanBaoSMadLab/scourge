# 函数

## 7.1 注解可选，也可写全

参数与返回类型都可以省略，由调用点与 `return` 自动推断：

```python
def add(a, b):
    return a + b

def main():
    print(add(1, 2))     # 3，实例化为 int
    print(add(1.5, 2))   # 3.5，实例化为 float
    return 0
```

规则：

- 变量类型由初值推断；
- 无注解参数是泛型模板，调用点按实参类型单态化；
- 无 `-> T` 时，返回类型由各 `return` 分支推断。

**完整注解同样完全支持**，签名即契约，跨模块 `.sgi` 与 AOT 布局都以此为准：

```python
def add(a: int, b: int) -> int:
    return a + b
```

以下情况必须写返回注解：

| 场景 | 错误码 |
|---|---|
| 递归或前向引用 | E2001 |
| `return` 分支类型冲突（如 `str` 与 `None`、`ok(v)` 与 `err(e)`） | E2006 |
| 返回从未写入的空容器 | E2002 |

```
t06_funcs.sg:4:12: error[E2001]: 函数 'fib' 的返回类型为自动推断且调用递归/前向引用（无法自动推断）；请为其显式注解返回类型
```

## 7.2 默认参数

默认参数在调用点生效：省略实参取默认值，显式传入则覆盖。

```python
def repeat(s, times = 2):
    """重复字符串。"""
    out = ""
    for i in range(times):
        out = out + s
    return out

def main():
    print(repeat("ab"))      # abab
    print(repeat("ab", 3))   # ababab
    return 0
```

带默认值的参数可以不传；实参少于必传参数个数或超出总参数个数才报 E2001「实参数量不匹配」。`.sgi` 接口把默认值记录为 `<default>`。

## 7.3 递归

递归调用时函数尚未完成推断，必须显式注解返回类型：

```python
def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)
```

调用帧在虚拟机/AOT 代码中常规分配。`fib(30)` 在本机 VM 模式实测 908ms、AOT 模式 6.8ms（第 15 章）——递归深度没有特殊限制（受栈约束），但请注意 AOT 模式下深层递归的栈用量与 C 程序相同。

## 7.4 无返回值函数与 None

```python
def noReturn():
    print("called")
```

没有 `return 值` 的函数自动推断为 `None`，也可以显式写 `def noReturn() -> None:`。`None` 也是字面量（`print(None)` → `None`），可以作为"空值"传递给接受相应类型的上下文。

## 7.5 参数遮蔽

参数在函数体内就是局部变量，可以重新赋值：

```python
def shadow(x):
    x = x + 1
    return x        # shadow(41) → 42
```

这是值语义：重新赋值不影响调用方的实参。

## 7.6 函数是模块级命名空间成员

函数只能定义在模块顶层（没有嵌套函数、没有闭包、没有 lambda）。函数可以被同模块其他函数调用，也可以被 `import` 它的模块以 `模块名.函数名` 调用（第 10 章）。

**函数不是头等值**：不能把函数名当变量传递，`print(add)` 报 E1007「函数作为头等值将在 P1 提供」。

## 7.7 完整示例

> **实测记录**（VM 与 AOT 输出逐字一致）：
> ```
> $ scg run t06_funcs.sg
> abab
> ababab
> 55
> called
> 6.5
> 42
> ```

对应源码：

```python
def repeat(s, times = 2):
    """重复字符串 times 次。"""
    out = ""
    for i in range(times):
        out = out + s
    return out

def fib(n: int) -> int:
    """递归：返回类型无法自动推断，必须注解。"""
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

def noReturn():
    print("called")

def defaults(a, b = 10, c = 1.5):
    return a + b + c

def shadow(x):
    x = x + 1
    return x

def main():
    print(repeat("ab"))          # abab
    print(repeat("ab", 3))       # ababab
    print(fib(10))               # 55
    noReturn()                   # called
    print(defaults(1, 2, 3.5))   # 6.5
    print(shadow(41))            # 42
    return 0
```
