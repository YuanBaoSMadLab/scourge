# 运算符与表达式

## 5.1 运算符总表

优先级从低到高（结合性除标注外均为左结合）：

| 优先级 | 运算符 | 说明 |
|---|---|---|
| 1 | `or` | 逻辑或 |
| 2 | `and` | 逻辑与 |
| 3 | `not` | 逻辑非（一元） |
| 4 | `== != < <= > >=`、`in` | 比较、成员测试 |
| 5 | `+ -` | 加、减（字符串 `+` 为拼接） |
| 6 | `* / // % @` | 乘、真除、地板除、取模、矩阵乘 |
| 7 | `-x +x` | 一元正负 |
| 8 | `**` | 幂，**右结合** |

记忆锚点：与 Python 完全一致，只有两处值得单独记住——`**` 优先于一元负号（`-2 ** 2` 得 `-4`），以及 `@` 与乘除同级。

## 5.2 算术运算符

```
1 + 2            → 3
1 + 2.0          → 3.0        （任一侧 float → float）
4 / 2            → 2.0        （真除法恒 float）
7 // 2           → 3          （地板除）
-7 // 2          → -4         （Python 同号修正）
-7 % 3           → 2          （取模与除数同号）
2 ** 10          → 1024       （int）
2 ** -1          → 0.5        （负指数 → float）
2 ** 3 ** 2      → 512        （右结合：2 ** (3 ** 2)）
-2 ** 2          → -4         （幂优先于一元负号）
```

字符串的 `+` 是拼接、`*` 是重复（`"ab" * 3` → `"ababab"`）。`str` 与 `int` 的 `+` 不被允许（无隐式字符串化，拼接请显式 `str(...)`）。

## 5.3 比较运算符

- 数值按大小；字符串按字典序（`"abc" < "abd"` → True）；
- **不可链式连写**：`1 < 2 < 3` 报 E1007「不支持链式比较；请用 and 显式组合」，请写 `1 < 2 and 2 < 3`；
- `==` / `!=` 支持全部可比较类型。

## 5.4 逻辑运算符

`and` / `or` / `not`，`and` 优先于 `or`：

```
True or False and False   → True     （先算 and）
not 1 == 2                → True     （not 优先于 ==）
not False                 → True
```

## 5.5 成员测试 in

`in` 支持 str、List、Dict（按键）、Set：

```
"ell" in "hello"          → True     （str 子串）
"a" in ["a", "b"]         → True     （List 元素）
2 in [1, 2, 3]            → True     （一维数值字面量是 List[int]）
2 in {1, 2, 3}            → True     （Set 元素）
"a" in {"a": 1}           → True     （Dict 键）
```

**张量不支持 `in`**。数值成员测试用 `List[int]` 或 `Set[int]`，不要用张量。

## 5.6 矩阵乘 @

`@` 仅接受两个二维张量，`(m, k) @ (k, n) → (m, n)`；内维不符编译期报 E2004，运行时形态不符 panic。张量运算的完整语义在第 11 章。

## 5.7 三元条件表达式

```python
a if cond else b
```

两分支类型须一致（或可按数值规则统一）：

```
"big" if c > b else "small"    → big
1 if c > b else 2.5            → 1       （int 分支胜出）
```

三元在 Scourge 里最常见的用途是构造"默认值"模式，例如 `r.unwrap(default)` 的标量版本。

对应源码（节选）：

```python
def main():
    print(1 + 2)                    # 3
    print(1 + 2.0)                  # 3.0
    print(4 / 2)                    # 2.0
    print(7 // 2)                   # 3
    print(-7 // 2)                  # -4
    print(-7 % 3)                   # 2
    print(2 ** 10)                  # 1024
    print(2 ** -1)                  # 0.5
    print(2 ** 3 ** 2)              # 512
    print(2 + 3 * 4)                # 14
    print(-2 ** 2)                  # -4
    print(1 + 2 < 4)                # True
    print(not 1 == 2)               # True
    print(True or False and False)  # True
    a = 1
    b = 2
    c = 3
    print(a < b and b < c)          # True（链式比较请用 and）
    print("abc" < "abd")            # True（字符串字典序）
    print("big" if c > b else "small")   # big
    print(1 if c > b else 2.5)          # 1
    print(-(3 - 5))                 # 7
    print(+7)                       # 7
    print(not False)                # True
    names = ["x", "y"]
    print("y" in names)             # True
    print("z" in names)             # False
    return 0
```
