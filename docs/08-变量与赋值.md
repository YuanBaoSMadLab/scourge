# 变量与赋值

## 3.1 直接赋值：没有 var，也没有 let

```python
x = 42
pi = 3.14
name = "scourge"
flag = True
```

直接赋值即创建变量，类型由初值推断。函数内对名称赋值即创建局部变量；读取外层名称按词法作用域解析（模块顶层常量、函数）。

## 3.2 推断赋值与注解赋值

注解是可选的：不写注解时类型由初值推断，写了注解则按注解校验并做隐式转换。

```python
n = 10                                        # 推断 int
ratio = 0.5                                   # 推断 float
label = "v1"                                  # 推断 str
m = [[1.0, 0.0], [0.0, 1.0]]                  # 推断 Tensor[float, (2, 2)]
```

全型注解写法与上面完全等价，在需要明确类型契约时使用：

```python
n: int = 10
ratio: float = 0.5
label: str = "v1"
m: Tensor[float, (2, 2)] = [[1.0, 0.0], [0.0, 1.0]]
```

注解与推断类型不符，编译期报 E2001：

```
_neg_ch08_type.sg:2:21: error[E2001]: 赋值类型不匹配：List[str] 无法赋给 List[int]
  2 |     xs: List[int] = ["a", "b"]
    |                     ^~~~~~~~~~
```

注解只约束类型，不改变值；但注解触发运行期转换，例如 `f: float = 3` 打印 `3.0`（详见 4.2）。

## 3.3 重复赋值

同一变量再次赋值，类型必须一致：

```python
x = 42
x = x + 1        # OK，仍是 int
x = "hello"      # E2001：str 无法赋给 int
```

张量的重复赋值还要求形状一致（形状是类型的一部分）。

## 3.4 增强赋值

标量的增强赋值完整支持：`+=` `-=` `*=` `/=` `//=` `%=` `**=`。字符串的 `+=` 是拼接：

```python
n = 10
n += 5           # 15
label = "v1"
label += "-beta" # "v1-beta"
```

语句之间**不能**用分号连接，每行一条语句。

**张量与标量的增强赋值当前不支持**：`t *= 2.0` 会报错，请写展开形式 `t = t * 2.0`。

```
_neg_tensor_aug.sg:4:5: error[E2001]: 运算符 '*=' 不支持 Tensor[float, (2, 2)] 与 float
```

## 3.5 声明式注解（无初值）——必须带初值

```python
count = 0           # ✅ 最简写法，推断 int
count: int = 0      # ✅ 声明类型并初始化
count: int          # ❌ E2002：声明缺少初值
```

Scourge **没有未初始化变量**——任何声明都必须带初值。裸声明 `count: int`（只有类型、没有 `=` 初值）会在检查期直接报 `E2002`：

```
count.sg:2:5: error[E2002]: 变量 'count' 声明需要初值（Scourge 无未初始化变量）；请写作 x: <类型> = <初值>，或直接 x = <初值>
run 中止：模块未通过全量验证
```

> **规则**：裸声明（只给类型不给初值）在检查期即被明确拒绝（E2002），不存在"先放行后崩溃"的窗口。
>
> **写法纪律**：优先直接写 `x = <初值>` 让类型从初值推断；只有需要强制类型契约时才补注解。

## 3.6 空容器与延迟定型

`[]` 没有元素可供推断，其元素类型在后续写入处**延迟定型**：

```python
ys = []              # 此刻元素类型未知
ys.append(1)         # 由实参定型为 List[int]
ys.append(2)

zs = []
zs.append("a")       # 定型为 List[str]
```

若到作用域结束仍无任何线索，检查期报 E2002：

```
_doc_ch08_empty.sg:2:5: error[E2002]: 无法推断 'xs' 的元素类型；请添加类型注解（如 xs: List[int] = ...）
  2 |     xs = []
    |     ^~~~~~~
```

定型线索包括：`append` 实参、下标写入、作为实参传入、`return`。也可以一开始就注解：

```python
xs: List[int] = []
xs.append(1)         # 输出 [1]
```

**非空数值列表直接可写**：`[1, 2, 3]` 的字面量类型是 `List[int]`（字面量规则详见 4.3），不恒为张量：

```python
xs = [1, 2, 3]
print(xs)            # [1, 2, 3]
print(len(xs))       # 3
```

## 3.7 完整示例

```python
def main():
    x = 42
    n = 10
    x = x + 1                   # 43
    n += 5
    n -= 1
    n *= 3                      # 14 → 13 → 39
    ratio = 0.5
    ratio /= 2.0                # 0.25
    label = "v1"
    label += "-beta"            # 字符串拼接
    count = 0
    xs = ["a", "b", "c"]
    print(x)                    # 43
    print(n)                    # 42
    print(ratio)                # 0.25
    print(label)                # v1-beta
    print(count)                # 0
    print(xs)                   # ["a", "b", "c"]
    print(len(xs))              # 3
    print(xs[0], xs[2])         # a c（print 多参数空格分隔）
    t = [[1.0, 2.0], [3.0, 4.0]]
    t = t * 2.0                 # 张量增强赋值用展开形式
    print(t)                    # Tensor(2, 2) [[2.0, 4.0], [6.0, 8.0]]
    return 0
```

VM 与 AOT 输出逐字一致：

```
43
42
0.25
v1-beta
0
["a", "b", "c"]
3
a c
Tensor(2, 2) [[2.0, 4.0], [6.0, 8.0]]
```

注意 `print` 的多参数行为：参数间以空格分隔、末尾换行，如 `print(xs[0], xs[2])` 输出 `a c`。

全型注解版本（与上例等价，`n` 的推算是 `int`、`ratio` 是 `float`、`label` 是 `str`、`count` 是 `int`、`xs` 是 `List[str]`、`t` 是 `Tensor[float, (2, 2)]`）：

```python
def main() -> int:
    x: int = 42
    n: int = 10
    ratio: float = 0.5
    label: str = "v1"
    count: int = 0
    xs: List[str] = ["a", "b", "c"]
    t: Tensor[float, (2, 2)] = [[1.0, 2.0], [3.0, 4.0]]
    ...
```
