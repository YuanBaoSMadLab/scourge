# 装饰器与声明边界

## 09.1 白名单：七个，一个不多

当前装饰器白名单：`@pure` `@jit` `@hardware` `@irq` `@realtime` `@no_runtime` `@extern`。使用白名单外的装饰器编译期拒绝（E1007）。这张表就是全部：

| 装饰器 | 形态 | 当前语义 |
|---|---|---|
| `@pure` | 无参 | 声明无副作用，记录进 `.sgi` 签名，参与契约相关检查 |
| `@jit` | 无参 | 前向标注：热点函数 JIT 升级（面向未来） |
| `@hardware` | 无参 | 前向标注：硬件后端 |
| `@irq` | 可带参 `@irq(7)` | 前向标注：中断处理 |
| `@realtime` | 关键字参 `@realtime(deadline_us=1000)` | 前向标注：实时约束 |
| `@no_runtime` | 无参 | 前向标注：无运行时模式 |
| `@extern("msvcrt.dll")` 等 | 字符串参（库名） | C ABI 真实入口：函数体允许一条 `pass` 或 docstring，运行时真正链接并调用外部 C 函数（FFI，见第 22 章）；模块需 `capability ffi` |

## 09.2 两类语义，必须分清

**`@pure` 是唯一有实际检查语义的装饰器**：它向编译器声明"此函数无副作用"，该声明进入 `.sgi` 接口供依赖方查看，并参与契约相关检查（例如纯函数的调用可在编译期折叠的语境中被识别）。

**其余五个（`@jit` `@hardware` `@irq` `@realtime` `@no_runtime`）是前向标注**：面向 MLIR/AOT 与硬件后端，当前只做语法校验，**不改变执行行为**。给函数贴 `@jit` 不会让它变快，贴 `@hardware` 不会让它上 GPU——它们是为未来的编译通路预留的元数据。

装饰器参数有两处特殊规则：关键字参数形式（`deadline_us=1000`）**仅装饰器可用**（普通函数调用不支持关键字参数）；`@extern` 只接受字符串参数。

## 09.3 @extern：纯声明的严格规则

```python
@extern("c")
def cAbs(x: int) -> int:
    pass
```

`@extern` 函数是 C ABI **真实入口**：**函数体允许一条 `pass` 或一条 docstring**（D2 修复，docstring-only 体已合法），运行时真正链接并调用外部 C 函数——`@extern` 在 成为可用的 FFI 机制（H 专项落地标量域，O 专项落地变参 `...` 与 `data_ptr` 地址透传），`cAbs` 这样的声明可被实际调用，前提是模块首部声明 `capability ffi` 且参数/返回仅限标量（int/float/bool/str/none）。完整契约见第 22 章。

> **避坑**：`@extern` 函数体允许 `pass` 或仅 docstring；`@extern` 真正调用 C 实现——可直接接入 C 库（FFI 详见第 22 章）。注意：参数与返回仅限标量、`@extern` 声明不支持缺省值；变参 `...` 仅允许出现在 `@extern` 上（本语言普通函数一律定参）。

## 09.4 完整示例

> **实测记录**（`t14_decorators.sg` 全量输出）：
> ```
> $ sg run t14_decorators.sg
> 42
> 2.5
> 5
> 7
> 8
> 0
> ```

对应源码：

```python
@pure
def pureFn(x):
    """纯函数：无副作用，记录进 .sgi 签名。"""
    return x * 2

@jit
def jitFn(x):
    """热点函数 JIT 升级（前向标注）。"""
    return x + 1.0

@hardware
def hwFn(x):
    """硬件后端标注（前向标注）。"""
    return x

@extern("c")
def cAbs(x: int) -> int:
    pass

@no_runtime
def noRt(x):
    """无运行时模式（前向标注）。"""
    return x

@realtime(deadline_us=1000)
def rtFn(x):
    """实时标注（前向标注，关键字参数仅装饰器可用）。"""
    return x

@irq(7)
def irqFn():
    """中断标注（前向标注）。"""
    return 0

def main():
    print(pureFn(21))      # 42
    print(jitFn(1.5))      # 2.5
    print(hwFn(5))         # 5
    print(noRt(7))         # 7
    print(rtFn(8))         # 8
    print(irqFn())         # 0
    return 0
```

除 `@extern` 外，装饰器不影响类型推断：参数与返回类型照常自动推断，也可写全型。`@extern` 声明的是 C ABI 入口，参数与返回必须显式标注（FFI 需要确定签名），故 `cAbs` 保留完整类型。
