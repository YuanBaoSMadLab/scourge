# 附录 A 内建函数速查

>

## A.1 输出与转换（零能力）

| 函数 | 签名 | 行为 |
|---|---|---|
| `print(...)` | 任意个参数 | 打印到 stdout，空格分隔、末尾换行；接受任意类型 |
| `str(x)` | `x` → `str` | 支持 int/float/bool/str/Tensor；List/Result 编译期拒绝；浮点最短往返、整数值补 `.0` |
| `len(x)` | `x` → `int` | 支持 List/str（按字节）/Dict（注解层）；张量编译期拒绝 |

## A.2 数学（标量 + 张量逐元素，零能力）

| 函数 | 签名 | dtype 规则 |
|---|---|---|
| `abs(x)` | 数值或张量 → 同 dtype | **保 dtype**：int→int、float→float、张量保元素类型 |
| `sqrt(x)` | 数值或张量 → float | **恒 float**（int 输入提升）；负数得 `nan`，不 panic |
| `exp(x)` | 同上 | 同上 |
| `log(x)` | 同上 | 同上；`log(0)` 得 `-inf`，不 panic |

### A.2.1 扩展数学（零能力）

| 函数 | 签名 | 行为 |
|---|---|---|
| `sin(x)` / `cos(x)` / `tan(x)` | 数值 → float | 三角函数（弧度） |
| `asin(x)` / `acos(x)` / `atan(x)` | 数值 → float | 反三角函数（弧度） |
| `sinh(x)` / `cosh(x)` / `tanh(x)` | 数值 → float | 双曲函数 |
| `atan2(y, x)` | 两数值 → float | 四象限反正切（注意参数顺序 y, x） |
| `floor(x)` / `ceil(x)` / `trunc(x)` | 数值 → **int** | 取整：`floor(2.5)=2`、`ceil(2.5)=3`、`trunc(-2.7)=-2`（**返回整数**） |
| `round(x)` | 数值 → int | 四舍五入到最近整数 |

> 实测：`floor/ceil/trunc/round` 返回 `int`；其余数值与 IEEE 一致。

## A.3 归约（零能力）

| 函数 | 签名 | 规则 |
|---|---|---|
| `sum(t)` | 张量或数值列表 → 元素类型标量 | 接受 `Tensor` 与 `List[int]`/`List[float]`；int 累加带溢出 panic；float 行主序顺序累加 |
| `max(t)` / `min(t)` | 张量或数值列表 → 元素类型标量 | 接受 `Tensor` 与 `List[int]`/`List[float]`；空序列运行时 panic。**无多参标量版本** |

## A.4 形状与构造（零能力）

| 函数 | 签名 | 规则 |
|---|---|---|
| `transpose(t)` | 二维张量 → 转置 | 仅二维（其他秩 E2004）；dtype 不变；值语义新张量 |
| `reshape(t, d1, ...)` | 张量 + 正 int 字面量 | 元素总数须一致（静态 E2004 / 动态维运行时 panic）；行主序不变 |
| `range(n)` | int → 区间 | 仅用于 `for`；`n<=0` 空区间；不是列表（无 len/下标） |

## A.5 Result 构造（零能力）

| 函数 | 签名 | 规则 |
|---|---|---|
| `ok(v)` | 1 参 → `Result[T, E]` | 成功构造出口 |
| `err(msg)` | 1 参（str）→ `Result[T, E]` | 失败构造出口 |

> 计时与休眠（`now` / `sleep(ms)`）属于 `time` 能力域，须声明 `capability time`（见 A.7.5），**非零能力**。

## A.5b 随机与排序（零能力）

| 函数 | 签名 | 规则 |
|---|---|---|
| `seed(n)` | int → 无返回 | 设置确定性随机数种子（复现实验用） |
| `random()` | 无参 → float | 返回 `[0,1)` 均匀浮点；未 `seed` 时不可复现 |
| `sorted(xs)` | `List[T]` → `List[T]` | 返回排序后的**新列表**；仅接受 List，张量报 E2001 |
| `reversed(xs)` | `List[T]` → `List[T]` | 返回逆序后的**新列表**；仅接受 List |

> 实测：`seed(42)` 后 `random()` 双模一致；`sorted([3,1,2])` → `[1, 2, 3]`；`reversed([3,1,2])` → `[2, 1, 3]`。

## A.6 纯计算内建：哈希与 JSON（零能力，M 专项）

| 函数 | 签名 | 规则 |
|---|---|---|
| `sha256(s)` | `str` → `str` | 返回 64 字符十六进制 SHA-256 摘要；确定性，零能力 |
| `crc32(s)` | `str` → `int` | 返回 32 位 CRC-32（IEEE 802.3 多项式）；确定性，零能力 |
| `json_decode(s)` | `str` → `Json` | 解析 JSON 文本为动态 `Json` 值；解析失败运行时 panic（含越界下标/类型不匹配） |

> 实测：`sha256("abc")` → `ba7816bf...20015ad`（NIST 向量一致）；`crc32("abc")` → `891568578`；`json_decode` 支持对象/数组/字符串/数字/布尔/null 与嵌套。

### A.6.1 `Json` 值成员方法（零能力，M 专项）

| 成员 | 签名 | 行为 |
|---|---|---|
| `get(key)` | `str` → `Json` | 取对象字段；缺失返回 `null` 值（不 panic） |
| `at(idx)` | `int` → `Json` | 取下标元素；越界运行时 panic |
| `len` | ` → int` | 对象字段数 / 数组元素数 |
| `keys` | ` → List[str]` | 对象字段名列表 |
| `dump` | ` → str` | 序列化回 JSON 文本 |
| `is_obj` / `is_list` / `is_str` / `is_int` / `is_float` / `is_bool` / `is_null` | ` → bool` | 类型判别 |
| `as_int` / `as_float` / `as_bool` / `as_str` | ` → 标量` | 类型取出；类型不符运行时 panic |

> 实测（`probe_json_acc.sg`）：对象/数组/标量存取、`at` 越界 panic、`get` 缺失返回 null、嵌套 `at` 链、各 `is_*`/`as_*` 均双模一致。

## A.7 能力门禁域内建

能力域共七：`io` `net` `env` `proc` `time` `signal` `ffi`。未声明对应域而使用该域内建 → 编译期 `E5004`；运行期另有 `sg_cap_check` 双门禁。下面列出全量声明，并标注重测状态。

### A.7.1 `io` 域（文件与标准输入）

| 函数 | 签名 | 规则 | 复测 |
|---|---|---|---|
| `input` | ` → str` | 从 stdin 读一行（**无参数**，不接受提示串） | ✓ |
| `read_text(path)` | `str → str` | 读取文本文件全部内容 | ✓ |
| `write_text(path, s)` | `str, str → 无返回` | 写入文本文件（覆盖） | ✓ |
| `append_text(path, s)` | `str, str → 无返回` | 追加文本文件 | ✓ |
| `exists(path)` | `str → bool` | 路径是否存在 | ✓ |
| `list_dir(path)` | `str → List[str]` | 目录条目名列表 | ✓ |

### A.7.2 `net` 域（网络）

| 函数 | 签名 | 规则 | 复测 |
|---|---|---|---|
| `net_http_get(url)` | `str → str` | 同步 HTTP GET，返回响应体文本 | ✓ |
| `net_connect` / `net_send` / `net_recv` / `net_close` | 套接字操作 | TCP 连接/收发/关闭（send/recv/close 已随服务端实测；`net_connect` 客户端路径未单测） | ✓ 部分 |
| `net_bind` / `net_accept` / `net_set_timeout` | 套接字操作 | TCP 监听/接受/超时（bind 为两参 addr+port；**监听→accept→recv/send→close 全链路已实测**） | ✓ |
| `net_udp_send` | UDP 发送 | UDP 单报发送 | — 声明 |

### A.7.3 `env` 域（环境变量）

| 函数 | 签名 | 规则 | 复测 |
|---|---|---|---|
| `env(name)` | `str → str` | 读环境变量；缺失返回空串 | ✓ |
| `has_env(name)` | `str → bool` | 环境变量是否存在 | ✓ |
| `set_env(name, val)` | `str, str → str` | 设置环境变量（返回新值） | ✓ |
| `unset_env(name)` | `str → 无返回` | 删除环境变量 | ✓ |

### A.7.4 `proc` 域（进程）

| 函数 | 签名 | 规则 | 复测 |
|---|---|---|---|
| `system(cmd)` | `str → int` | 同步执行 shell 命令，返回退出码 | ✓ |
| `spawn_wait(cmd, argv)` | `str, List[str] → int` | 启动子进程（第二参为 `List[str]` 形态 argv），等待并返回退出码 | ✓ |

### A.7.5 `time` 域（时钟）

| 函数 | 签名 | 规则 | 复测 |
|---|---|---|---|
| `now()` | 无参 → float | 单调时钟秒（见 A.10，须 `capability time`） | ✓ |
| `sleep(ms)` | int（毫秒）→ 无返回 | 休眠（见 A.10） | ✓ |
| `epoch()` | 无参 → int | Unix 秒（自 1970-01-01 的秒数） | ✓ |
| `epoch_ms()` | 无参 → int | Unix 毫秒 | ✓ |
| `localtime(sec)` | int → `List[int]`（8 元） | 本地时间分解（tm 结构，年/月/日/时/分/秒/星期/年日） | ✓ |
| `gmtime(sec)` | int → `List[int]`（8 元） | UTC 时间分解 | ✓ |

> 注意：`localtime` / `gmtime` 为**单参**，传入 `epoch()` 的秒值，返回 8 元素 `List[int]`。

### A.7.6 `signal` 域（信号）

| 函数 | 签名 | 规则 | 复测 |
|---|---|---|---|
| `signal_caught()` | ` → bool` | 最近是否捕获到信号 | ✓ |
| `signal_reset()` | ` → 无返回` | 清除信号捕获状态 | ✓ |

### A.7.7 `ffi` 域（外部函数接口，H 标量域 / O 变参与 data_ptr）

| 形式 | 规则 | 复测 |
|---|---|---|
| `@extern("lib.dll") def f(...) -> T: pass` | 声明 C ABI 真实入口；函数体允许一条 `pass` 或 docstring；参数与返回仅限标量（int/float/bool/str/none），不支持缺省值 | ✓（标量域） |
| `@extern(...)` 末位 `...` 变参 | 仅允许出现在 `@extern` 声明；实参下限 = 命名参数个数，上限 20 | ✓（变参，MS x64 双 ABI） |
| `data_ptr(x)` | `x` 为 `Tensor`/`str` → 返回宿主地址 `int`；`str` 指向进程期稳定只读副本，`Tensor` 设备驻留时先回拷宿主 | ✓（接受 Tensor/str；`List` 拒绝 E2001） |

> 实测：`lstrlenA("hello")` → 5、`fabs(-3.5)` → 3.5（kernel32/msvcrt）；`printf("hi %d %.2f\n", 42, 3.5)` + `fflush(0)` → `hi 42 3.50`；`strlen(data_ptr("hello"))` → 5。跨模式可复现输出需 `printf` 后配同源 `fflush(0)`（见第 22 章）。

## A.8 `str` 成员方法（零能力）

**按字节处理**（UTF-8 字节语义，非字符数）；`upper`/`lower` 仅映射 ASCII 字母，非 ASCII 字节原样返回。

| 方法 | 签名 | 行为 | 复测 |
|---|---|---|---|
| `s.upper` | ` → str` | ASCII 转大写 | ✓ |
| `s.lower` | ` → str` | ASCII 转小写 | ✓ |
| `s.trim` | ` → str` | 去两端空白（空格/Tab/CR/LF） | ✓ |
| `s.trim_start` | ` → str` | 去首部空白 | ✓ |
| `s.trim_end` | ` → str` | 去尾部空白 | ✓ |
| `s.split(sep)` | `str → List[str]` | 按字节子串分割；`sep` 空串 → panic；无匹配 → 单元素列表 | ✓ |
| `s.join(parts)` | `List[str] → str` | 以 `s` 连接；元素须全为 str（静态检查） | ✓ |
| `s.replace(old, new)` | `str, str → str` | 全替换；`old` 空串 → panic | ✓ |
| `s.find(sub)` | `str → int` | 首次字节下标；无则 -1（不 panic） | ✓ |
| `s.index(sub)` | `str → int` | 同 `find`，但无则 panic | ✓ |
| `s.contains(sub)` | `str → bool` | 是否包含子串 | ✓ |
| `s.startswith(sub)` | `str → bool` | 是否以前缀开头 | ✓ |
| `s.endswith(sub)` | `str → bool` | 是否以后缀结尾 | ✓ |

### A.8.1 `List[T]` 成员方法（C-D 专项，零能力）

| 方法 | 签名 | 行为 | 复测 |
|---|---|---|---|
| `xs.index(v)` | `T → int` | 首次出现下标；无则 panic | ✓ |
| `xs.count(v)` | `T → int` | 出现次数 | ✓ |
| `xs.contains(v)` | `T → bool` | 是否包含 | ✓ |

## A.9 通用注意

- 内建名不可被用户重定义——**实际未强制**，请自律不要占用；
- 所有内建的参数个数/类型错误编译期报 `E2001`；
- `print` 对 List 句柄值  AOT 亦支持（`List[int]`/`List[str]` 双模一致）；**`print(Result)` 在 AOT 中仍不支持（E1007）**，VM 中可用；
- 能力门禁域内建：**未声明 `capability` 即编译期 `E5004`**，这是 AI 生成代码的副作用防火墙（第 19 章）。

## A.10 计时与休眠注意（避免踩坑）

- `now()` 返回**单调秒**，绝对偏移无意义；只应用其两次调用之差做计时，**必须包裹纯计算段**（不要含编译/字面量解析时间，否则会掩盖 AOT 与 VM 的真实差异）。
- `sleep(n)` 的参数是**毫秒**：`sleep(1000)` 才是 1 秒；`sleep(1)` 约 1 毫秒（受 Windows 调度量子 ~15.6ms 影响，实测约 14.6ms 地板）。

## A.11 不存在的内建（避坑）

| 想找的 | 现状 |
|---|---|
| `zeros` / `ones` / `eye` / `arange` | 不存在——张量只能字面量/程序构造 |
| `list(...)` / `dict(...)` | 不存在 |
| `int(...)` / `float(...)` / `bool(...)` | 不存在（转换靠字面量与注解） |
| `min`/`max` 的多参标量版本 | 不存在（Tensor / List 归约见 A.3） |
| 列表推导式 / f-string / `bytes` / 正则 / `yield` / `struct` / `enum` / 泛型 / 头等函数 | 语言级尚未实现 |
| `format` | 不存在（C-D 专项规划的字符串格式化尚未落地） |
