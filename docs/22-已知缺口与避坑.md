# 已知缺口与避坑

## 22.1 仍待解决的缺口

### `@` 的实现形态与文档描述有差异

文档称 `@` 矩阵乘降级为 linalg 结构化 op；实测生成的 `.ll` 中为 `@sg_tensor_matmul` 运行时调用。不影响正确性，影响性能预期——矩阵乘性能以第 17.2 节实测为准（AOT 已显著快于 VM）。
**绕行：无（性能以实测为准）。**

### 其他语言级与生态缺口

包生态；`@internal` 可见性粒度细化；FFI 指针算术/struct/union/callback；GPU 异步流 / concat / 单线程归约；`bytes`、正则、`yield`、`struct`/`enum`、泛型、头等函数；`async` 运行时语义（Task/调度器）。

完整缺口清单见仓库 `dev_feedback\缺失能力总清单.md`。

## 22.2 避坑速查表

| 想写 | 实际后果 | 应该写 |
|---|---|---|
| `count: int`（无初值） | **E2002** | `count = 0` 或 `count: int = 0` |
| `add(1)`（默认参数） | 可用，缺省值生效 | 直接写 |
| `xs: List[int] = [1,2,3]` | 可用 | 直接写 |
| `xs = [1,2,3]` | 推断为 `List[int]`（一维数值字面量不再是张量） | 直接写 |
| `xs.append(v)` | 可用（元素域 int/float/bool/str/Tuple，原地返回 None） | 直接写 |
| `xs = []` 且从不写入 | **E2002**（元素类型无从推断） | 先 `append`/下标写入定型，或写 `xs: List[int] = []` |
| `[x*c for x in d]`（Dict/Set 推导源） | E2001（源限 range/List/str） | 先 `for k in d` 取键再推导 |
| `build --target=aarch64-linux-gnu`（等号连写） | E5001（把等号串当模块名） | 参数空格分隔：`--target aarch64-linux-gnu --sysroot <musl> --static` |
| `for ch in "abc"` | 可用（按字节迭代） | 直接写 |
| 顺序循环都用 `i` | 合法 | 可保留 |
| **嵌套循环都用 `i`** | **合法且数值正确，语义同 Python** | 为可读性建议 `i`/`j` 不同名 |
| 顶层放 `A = [[...]]` 再 build | E1007 | 搬进函数局部 |
| 两个 256×256 矩阵再 build | 可直接 build | — |
| 遍历 `List[bool]` 再 build | 可直接 build | — |
| 顶层 `async def` 再 build | E1007 | 函数内嵌套定义 `async def` |
| `print(r)`（Result）再 build | E1007（print 该参数类型） | 用 `run` 查看，或按 `is_ok()`/`unwrap(回退值)` 拆值 |
| `print(d)`（容器值字典）再 build | E1007（AOT 句柄槽无类型标签） | 标量值字典直接 `print`；容器值按键取值打印 |
| `f"empty: {}"` / `f"{x:spec}"` | E1007（空插值/格式说明符） | `f"{x}"`；格式化用 `format` |
| `build --gpu` | 可用 | 大矩阵用它 |
| 省略 `-> T` | 可由 `return` 推断；递归/前向引用（E2001）、混返 `str`/`None`（E2006）、从未写入的空容器（E2002）除外 | 这几种场景显式写返回类型 |
| 省略参数注解 | 定义模块内部可用（调用点单态化）；**跨模块被导入时必须注解参数** | 被导入函数写 `def f(x: int):` |
| `n = none()` 后调用成员 | 推断为 `None`，无成员（E2003） | `n: Option[int] = none()` 或借助上下文 |
| `t *= 2.0`（张量增强赋值） | E2001（`*=` 不支持 Tensor 与 float） | `t = t * 2.0` |
| `n += 5; n -= 1`（分号连写） | E1001（非法字符 `';'`） | 每行一条语句 |
| 用 `sum`/`print` 当变量名 | E2007 | 换名 |
| `A = [` 后括号内换行 | 支持 | 可放心换行 |
| `1 < 2 < 3` | E1007（链式比较） | `1 < 2 and 2 < 3` |
| `f: float = 3` 后打印 | 输出 `3.0`（注解触发运行期转换） | 直接写 `3.0` 也行 |
| `2 ** -1` 再 build | E1007（AOT 不支持负指数） | 用 `1.0 / 2.0` |
| 非 `@extern` 函数写 `...` | E1007（变参仅限 extern 声明末位） | 本语言函数定参；变参走 `@extern` |
| `data_ptr(lst)`（List） | E2001（非连续原生数组） | 只传 `Tensor[int]`/`Tensor[float]`/`str` |
| `printf(fmt, ...21 个实参)` | E2001（超上限 20 = 桩栈槽 16+4） | ≤20 实参 |
| `@extern` 调用 / `data_ptr` 无 `capability ffi` | E5004 | 模块顶层加 `capability ffi` |
| `printf` 后不 `fflush(0)` | AOT 输出可能滞留 C 运行时缓冲 | 配同源 `@extern` 的 `fflush(0)` |
