# 附录 C 测试套件索引（verify/probes）

> 本书的全部示例来自 `D:\Scourge\verify/probes\`。每个文件头部标注对应章节，尾部注释记录期望输出。在仓库根目录按如下方式验证任意一个：
> ```powershell
> cd D:\Scourge\verify\probes
> scg check <file>.sg    # 静态检查
> scg run   <file>.sg    # 编译执行（输出与文件尾注释比对）
> ```

## C.4 如何用这套测试做回归

升级工具链后，最小回归集：

```powershell
# 1. 全量检查（应全部 OK）
scg check t*.sg

# 2. 双模一致（diff 应无输出）
scg run t16_dual_mode.sg > a.txt
scg build t16_dual_mode.sg -o t16.exe; .\t16.exe > b.txt
diff a.txt b.txt

# 3. 行为变更对照
scg run probe_seg_a1.sg        # 应报 E2002（旧版会段错误）
scg run probe_default.sg       # 应输出 3 / 11（默认参数可用）
scg build t18_bench_256.sg -o t256.exe; .\t256.exe   # 应正常输出矩阵结果（旧版 127 崩溃）
scg build --gpu t18_bench_224.sg -o g.exe           # 应接受 --gpu 并生成 GPU 二进制

# 4. 循环变量与性能验证
scg run probe_n_nested_same.sg   # 嵌套同名循环变量：输出 3
scg run probe_n_reply_example.sg # 嵌套同名循环变量：输出 4
scg run t18_bench_512.sg         # 对比 AOT 与 VM 耗时（AOT 比 VM 快约 18×）
scg build b4_booliter.sg -o b4.exe; .\b4.exe  # 遍历 List[bool] 可 build
```
