# 模块系统

## 10.1 一个模块就是两个文件

被导入方 `lib_greet.sg`：

```python
SCALE: float = 2.0
GREETING: str = "hello"

@pure
def scale(x: float) -> float:
    """标量乘以模块常量。"""
    return x * SCALE

def shout(text: str, times: int = 2) -> str:
    """重复字符串 times 次。"""
    out = ""
    for i in range(times):
        out = out + text
    return out
```

导入方 `t13_modules.sg`：

```python
import lib_greet

def main():
    print(lib_greet.scale(3.0))          # 跨模块函数
    print(lib_greet.shout("hi"))         # 默认参数生效
    print(lib_greet.shout("hi", 3))      # 显式传全实参
    print(lib_greet.GREETING)            # 跨模块顶层常量
    return 0
```

模块名即文件名（不含 `.sg`）；**模块名即命名空间**，成员访问一律 `模块名.成员名`。

### 跨模块边界上的注解要求

模块内部的函数可以完全省略注解（隐式单态化），但**被导入的函数必须显式标注参数类型**，否则导入方报 E2001：

```
t13_modules.sg:4:11: error[E2001]: 导入函数 'scale' 存在未注解参数——隐式单态化仅限定义模块内部调用；请在其定义处显式标注参数类型
```

原因是隐式单态化按调用点生成特化版本，跨模块调用无法把调用点信息带回定义模块。**返回类型仍可省略**，检查器会推断出具体类型并写进 `.sgi`：

```python
def twice(x: int):
    return x * 2          # .sgi: def twice(x: int) -> int
```

顶层常量同理：不注解不影响使用，但不会出现在 `.sgi` 契约里。

## 10.2 三条拒绝规则

解析层明确拒绝三种 Python 习以为常的形态：

| 形态 | 状态 |
|---|---|
| `from lib_greet import scale` | 拒绝 |
| `import lib_greet as g` | 拒绝 |
| `import a.b.c`（点分路径） | 拒绝 |

这是有意为之的简化：单一导入形态让依赖图静态可判定（DAG），`.sgi` 接口可以机械生成，多线程分层检查可以确定性地并行。代价是灵活性——接受它，或者等 P1。

## 10.3 搜索顺序

1. 先相对**导入方文件所在目录**；
2. 再相对**当前工作目录**。

找不到目标报 E5001_ModuleNotFound；循环依赖报 E5002_ImportCycle（DAG 前提被破坏）。被导入模块先做全量检查（含其自身依赖），**依赖有错则导入方也无法通过**——错误不会延迟到运行时。

## 10.4 .sgi：接口契约文件

`scg interface lib_greet.sg` 全量验证通过后生成 `.sgi`：

```
# scg interface v1（scg interface 工具生成，请勿手改）
# 模块: lib_greet
# 本文件是接口契约：依赖方只看这里，无需阅读实现。

module lib_greet

SCALE: float
GREETING: str

@pure
def scale(x: float) -> float:
    """标量乘以模块常量。"""

def shout(text: str, times: int = <default>) -> str:
    """重复字符串 times 次。"""
```

`.sgi` 记录导出的函数签名、装饰器（如 `@pure`）、顶层常量类型，供跨模块检查与工具消费——依赖方不需要阅读实现即可获得完整契约。默认参数在契约中记作 `= <default>`，调用方可以省略该实参。
