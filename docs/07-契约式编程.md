# 契约式编程

## 8.1 契约是什么

Scourge 把函数的**前置条件、后置条件、不变式**写进 docstring，由编译器在调用点做静态验证。契约不是注释——违反它，编译期就报错。

```python
@pure
def clamp(x: int, lo: int, hi: int) -> int:
    """将 x 限制在 [lo, hi]。
    requires: lo <= hi
    ensures: result >= lo and result <= hi
    """
    if x < lo:
        return lo
    if x > hi:
        return hi
    return x
```

参数与返回类型通常可省略，但**契约表达式会按静态类型检查**：`ensures` 里同时引用 `result` 与参数，签名须写全（本例去掉任一注解会报 E2001「运算符不支持 <未知>」）。只含 `requires` 的函数仍可自动推断——契约在调用点验证，类型由实参决定。

三个前缀按行识别：

| 前缀 | 语义 | 验证时机 |
|---|---|---|
| `requires:` | 前置条件 | **调用点**静态验证，可确定违反时报 E3001 |
| `ensures:` | 后置条件（`result` 指代返回值，仅此处可用） | 函数体内（当前以实现纪律保证） |
| `invariant:` | 不变式 | 同 ensures |

## 8.2 调用点静态验证

```python
print(clamp(150, 0, 100))    # 合法：lo=0 <= hi=100
print(clamp(150, 100, 0))    # E3001_ContractViolated：requires 被常量实参静态违反
```

常量实参让验证器可以"确定"违反——这是编译期错误。非常量实参（如传入变量）无法静态判定时，契约降级为运行时断言，并给 W3001_ContractDowngraded 警告：

```python
n = 200
print(pct(n, 1000))          # W3001：requires: whole > 0 降级为运行期检查
```

契约表达式类型错误（非 bool）报 E3002_ContractTypeError；空契约表达式同样报 E3002。

## 8.3 配套写法：Result 做显式运行时检查

当调用方无法在编译期证明前置条件成立时（例如 `whole` 来自用户输入），正确的工程姿势是**写一个返回 Result 的安全变体**，把"契约不可静态求值"的情况显式化：

```python
def safePct(part: int, whole: int) -> Result[float, str]:
    """用显式分支实现"运行时"前置检查（契约不可静态求值时的配套写法）。"""
    if whole <= 0:
        return err("whole 必须为正")
    return ok(part / whole)
```

于是同一个功能有两个入口：契约版（`pct`，调用点静态验证，性能路径）与安全版（`safePct`，错误即值，边界路径）。这是 Scourge 推崇的错误处理分层。

## 8.4 完整示例

> **实测记录**（`t07_contracts.sg` 全量输出）：
> ```
> $ sg run t07_contracts.sg
> 100
> 0
> 50
> 0.2
> False
> 0.25
> ```

对应源码：

```python
@pure
def clamp(x: int, lo: int, hi: int) -> int:
    """将 x 限制在 [lo, hi]。
    requires: lo <= hi
    ensures: result >= lo and result <= hi
    """
    if x < lo:
        return lo
    if x > hi:
        return hi
    return x

@pure
def pct(part, whole):
    """百分比：whole 必须为正。
    requires: whole > 0
    """
    return part / whole

def safePct(part: int, whole: int) -> Result[float, str]:
    """用显式分支实现"运行时"前置检查。"""
    if whole <= 0:
        return err("whole 必须为正")
    return ok(part / whole)

def main():
    print(clamp(150, 0, 100))      # 100（常量实参，requires 静态通过）
    print(clamp(-5, 0, 100))       # 0
    print(clamp(50, 0, 100))       # 50
    n = 200
    print(pct(n, 1000))            # 0.2（非常量实参，requires 降级运行期）
    r = safePct(1, 0)
    print(r.is_ok())               # False
    r2 = safePct(1, 4)
    print(r2.unwrap(0.0))          # 0.25
    return 0
```

`pct` 只有 `requires`，参数与返回类型由调用点/`return` 推断；`clamp` 的 `ensures` 需要完整签名；`safePct` 返回 `Result`，保留完整签名（原因见第 9 章）。全型写法始终可用。
