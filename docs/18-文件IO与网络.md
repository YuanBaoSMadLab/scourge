# 文件 IO 与网络

## 18.1 文件 IO（io 域）

```scourge
capability io

def main():
    write_text("note.txt", "hello")          # 写入（覆盖）
    print(read_text("note.txt"))             # hello
    append_text("note.txt", "world")         # 追加
    print(read_text("note.txt"))             # helloworld（无分隔符）
    print(exists("note.txt"))                # True
    print(exists("nope.txt"))                # False
    print(len(list_dir(".")) > 0)            # True：当前目录项个数
    return 0
```

| 内建 | 语义 |
|---|---|
| `write_text(path, s)` | 以 `str` 覆盖写入文件 |
| `append_text(path, s)` | 追加到文件末尾（**不**自动加换行） |
| `read_text(path)` | 读回整个文件为 `str` |
| `exists(path)` | 路径是否存在 → `bool` |
| `list_dir(path)` | 目录项列表 → `List[str]` |
| `input` | 从标准输入读一行 → `str` |

> 字符串按 UTF-8 字节处理（见第二十三章），`len` / 下标 / `find` / `split` 一律按字节，这是确定性语言的有意约定。

## 18.2 网络（net 域）

Scourge 内置了网络能力，无需外部库即可访问网络：

```scourge
capability net

def main():
    try:
        r = net_http_get("http://example.com")
        print(len(r) > 0)          # 收到响应则为 True
    except:
        print("net-unreachable")   # 网络不可达时优雅降级
    return 0
```

`net` 域还包含更底层的 TCP/UDP 原语（均为确定性 API，配对使用）：

| 内建 | 语义 |
|---|---|
| `net_http_get(url)` | 发起 HTTP GET，返回响应体 `str` |
| `net_connect(addr, port)` | 建立 TCP 连接，返回句柄 |
| `net_send(h, s)` / `net_recv(h, n)` | 发送 / 接收 |
| `net_close(h)` | 关闭连接 |
| `net_bind(addr, port)` / `net_accept(h)` | 服务端监听 / 接受（addr 如 `"127.0.0.1"`） |
| `net_set_timeout(h, ms)` | 设置超时 |
| `net_udp_send(addr, port, s)` | UDP 发送 |

> 实测：`net_http_get` 在联网环境会**真实发起请求并返回非空响应**；离线 / 沙箱隔离时由 `try/except` 捕获，不会崩溃。网络可达性属于运行期环境，不是语言缺陷。

## 18.3 能力门禁是统一的

无论是文件还是网络，只要碰外部世界就必须申报。`read_text` 未声明 `io` 会被 E5004 挡在编译期；声明后 VM/AOT 双模一致。把"这段代码会读盘 / 上网"变成一眼可见的模块级声明，正是能力模型的价值。

## 18.4 避坑

- `write_text` 是**覆盖**写；要追加必须用 `append_text`（注意它不加换行）。
- 网络调用一定要包 `try/except`：运行环境可能无网，未捕获的 panic 会以退出码 1 终止进程。
- `list_dir` 返回的是该目录下的条目名列表，不是递归树。
